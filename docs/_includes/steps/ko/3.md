Sim은 개인 작업 공간을 **workspace**라고 부릅니다. 이 작업 공간에서 AI 팀을 만들고 관리합니다.

이미 Personal Secrets에 `OPENROUTER_API_KEY`를 등록했고 사용할 수 있다면 4단계로 넘어가세요. Sim 계정만 있는 경우에는 아래 키 연결 과정도 진행해야 합니다.

## API 키 연결하기

1. <a href="https://www.sim.ai/" target="_blank" rel="noopener noreferrer">Sim(새 탭)</a>에 접속해 가입하거나 로그인하세요.
2. 필요한 이메일 인증을 완료하고 작업 공간을 여세요.
3. 화면 **왼쪽 위의 작업 공간 이름**을 클릭한 뒤 **Settings(설정) → Secrets(비밀값 보관)**를 여세요.
4. **Personal** 구역을 찾아 빈 줄에 아래 값을 입력하세요.

| 입력란 | 입력할 내용 |
| --- | --- |
| Key 또는 Name | `OPENROUTER_API_KEY` |
| Value | OpenRouter에서 복사한 개인 API 키 |

<ol start="5">
  <li><strong>Save(저장)</strong>를 누르세요.</li>
  <li>저장한 키의 이름을 확인한 뒤 Sim 작업 화면으로 돌아가세요.</li>
</ol>

직접 만들 AI 팀에서는 `OPENROUTER_API_KEY`라는 이름으로 저장된 키를 사용합니다. 예제에 표시된 `{% raw %}{{OPENROUTER_API_KEY}}{% endraw %}`는 저장된 키를 불러오는 표시이며, 실제 키가 아닙니다. [Sim 공식 설정 안내](https://docs.sim.ai/platform/credentials)

Personal Secrets는 본인만 사용할 수 있습니다. 이번 실습에서는 개인 OpenRouter 키를 Workspace 구역에 넣지 마세요.

**주의:** 키 이름과 실제 키를 서로 바꿔 입력하지 마세요. 설정을 찾기 어렵다면 진행자에게 문의하세요. 이름이 비슷한 **Sim API keys**는 이 단계에서 사용하는 기능이 아닙니다.
