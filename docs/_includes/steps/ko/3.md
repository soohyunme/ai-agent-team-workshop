이미 연결했나요? 이 작업 공간에 OPENROUTER_API_KEY가 저장돼 있고 사용할 수 있다면 그대로 두고 4단계로 넘어가세요. Sim 계정만 있는 경우에는 키 연결까지 완료해야 합니다.

Sim은 내 작업 공간을 **workspace**라고 부릅니다. 만든 팀은 이 공간에 저장됩니다.

1. 새 탭에서 [Sim](https://www.sim.ai/)을 열어 가입하거나 로그인합니다.
2. 요청되는 이메일 인증을 완료하고 내 작업 공간으로 들어갑니다.
3. 작업 공간의 **Settings(설정)**를 열고 **Secrets(비밀값 보관)**를 선택합니다.
4. Workspace 구역의 빈 줄에 다음 두 값을 입력합니다.

| 입력란 | 넣을 내용 |
| --- | --- |
| Key 또는 Name | `OPENROUTER_API_KEY`를 그대로 복사 |
| Value | OpenRouter에서 복사한 긴 개인 코드 |

5. **Save(저장)**를 누릅니다. 저장 후 코드가 가려져 보일 수 있습니다.
6. Sim의 작업 화면으로 돌아옵니다.

예제는 위 이름으로 저장된 코드를 찾아 씁니다. 예제 안의 `{% raw %}{{OPENROUTER_API_KEY}}{% endraw %}`는 '저장된 키를 사용하라'는 표시이지 실제 키가 아닙니다. [공식 설정 안내](https://docs.sim.ai/platform/credentials)

완료 확인: 저장한 키 이름이 보입니다. 설정 위치를 못 찾겠으면 해당 단계에서 도움을 요청하세요. 이름이 비슷한 'Sim API keys'는 다른 기능입니다.
