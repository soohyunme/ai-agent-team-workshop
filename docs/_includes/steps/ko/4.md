## 화면 구성 확인하기

화면의 상자 하나를 **블록(block)**이라고 부릅니다. 다음 네 블록이 순서대로 연결돼 있는지 확인하세요.

| 블록 이름 | 역할 |
| --- | --- |
| Start | 여행 요청과 장소 자료 입력 |
| Sightseeing Planner | 관광 활동과 지역 선택 |
| Food Planner | 선택된 지역에서 음식 취향에 맞는 후보 선택 |
| Trip Planner | 관광·식사·휴식을 하나의 일정으로 구성 |

**모델(model)**은 답변을 생성하는 AI를 뜻합니다. 이번 실습에서는 템플릿에 지정된 모델을 그대로 사용합니다.

## 제공 자료의 범위

이번 실행에서는 **제공된 관광·식사 자료**를 바탕으로 일정 초안을 작성합니다. 실시간 검색이나 예약은 하지 않습니다. 식사 후보는 **실습용 가상 예시**이며 실제 식당이나 메뉴 정보가 아닙니다.

Start의 places에는 관광 자료와 실습용 가상 식사 자료가 함께 들어 있습니다. 각 항목에는 식별 번호와 지역이 표시돼 있습니다. 식사 담당이 지역을 어떻게 활용하는지 확인할 때 사용합니다.

관광지의 간단한 소개와 지역은 [홍콩 관광청의 침사추이 명소 안내](https://www.discoverhongkong.com/eng/attractions/top-things-to-see-and-do-around-tsim-sha-tsui-promenade.html)와 [아트파크 안내](https://www.discoverhongkong.com/eng/place-to-go/travel.guide-art-park.html)를 참고했습니다. 식사 자료는 이 출처의 식당 정보가 아니라 교육을 위해 만든 예시입니다.
