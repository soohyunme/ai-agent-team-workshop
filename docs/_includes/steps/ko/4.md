## A. 새 워크플로 만들기

**워크플로(workflow)**는 작업의 실행 순서와 정보 전달을 구성한 것입니다. 이번에는 완성본을 불러오는 대신 직접 만들어봅니다.

1. Sim 왼쪽 **Workflows 옆 +**를 눌러 새 워크플로를 만드세요.
2. 목록의 새 워크플로 이름을 우클릭하고 **Rename**으로 `My Hong Kong Team`이라고 이름을 붙이세요.
3. **Start**가 있는지 확인하세요. 없다면 오른쪽 **Toolbar**에서 Start를 찾아 빈 작업 화면으로 끌어오세요. Start는 하나만 둡니다.

화면의 상자 하나를 **블록(block)**이라고 합니다. 기본 실습에서는 Start와 세 Agent 블록을 사용합니다.

## B. 짧은 여행 요청 입력하기

Start를 클릭하고 **Editor**를 여세요. 입력 항목의 **+**로 아래 세 항목을 만들고 **Name·Type·Value**를 입력하세요. Description은 선택 사항입니다.

| Name | Type | Value | 의미 |
| --- | --- | --- | --- |
| interests | string | `harbour views, photography, parks` | 관광 관심사 |
| food | string | `local dishes` | 음식 취향 |
| pace | string | `relaxed` | 여행 속도 |

`string`은 글자로 된 값이라는 뜻입니다. Name은 가이드와 똑같이 입력하세요. 이 이름을 사용해 에이전트가 요청을 읽습니다.

## C. 공통 자료 준비하기

관광·식사 자료는 세 담당자가 함께 읽을 수 있도록 한 곳에 보관합니다. 자료 등록은 준비 작업이므로 아래 내용을 그대로 복사하면 됩니다.

1. 오른쪽 패널 상단, **Chat / Toolbar / Editor 탭 위의 ··· → Variables**를 여세요. 왼쪽 Workflows 옆 메뉴와는 다릅니다.
2. Variables 창의 **+**를 누르세요.
3. **Name**에 `cards`, **Type**에 `Object`를 지정하세요.
4. **Value**에 아래 내용을 중괄호까지 전부 복사해 붙여넣으세요. 이 칸은 여러 줄의 자료를 다룰 수 있습니다.
5. 오류 표시가 없는지 확인하고 Variables 창을 닫으세요.

Object는 여러 정보를 묶어 저장하는 형식입니다. 이번에는 문법을 배우거나 직접 수정할 필요가 없습니다. 아래 코드는 API 키가 아니라 공통 여행 자료입니다.

## 제공 자료의 범위

이번 실행에서는 **제공된 관광·식사 자료**를 바탕으로 일정 초안을 작성합니다. 실시간 검색이나 예약은 하지 않습니다. 식사 후보는 **실습용 가상 예시**이며 실제 식당이나 메뉴 정보가 아닙니다.

관광·식사 자료는 **공통 자료(cards)**에 저장하고, 세 에이전트가 같은 자료를 참조합니다. Start에는 수정할 여행 취향만 있습니다. 이번 실습에서는 공통 자료를 편집할 필요 없이 아래 표로 내용을 확인하세요.

### 관광 자료

| 번호 | 장소 | 지역 | 관심사 |
| --- | --- | --- | --- |
| S1 | Avenue of Stars | Tsim Sha Tsui | 항구 풍경·사진·홍콩 영화 |
| S2 | Hong Kong Museum of Art | Tsim Sha Tsui | 예술 |
| S3 | Art Park | West Kowloon | 공원·항구 풍경·사진 |

### 식사 자료 — 실제 식당이 아닌 가상 예시

| 번호 | 식사 예시 | 지역 | 음식 취향 |
| --- | --- | --- | --- |
| F1 | 딤섬 (Example dim sum meal) | Tsim Sha Tsui | 현지 음식 |
| F2 | 채소 밥 (Example vegetable rice meal) | Tsim Sha Tsui | 채식 |
| F3 | 면 요리 (Example noodle meal) | West Kowloon | 현지 음식 |
| F4 | 채소 면 요리 (Example vegetable noodle meal) | West Kowloon | 채식 |

식별 번호와 지역은 관광 담당의 결과를 식사 담당이 어떻게 활용하는지 확인하기 위한 표시입니다. 휴식도 확인된 장소가 아니라 일정에 포함하는 계획 항목입니다.

관광지의 간단한 소개와 지역은 [홍콩 관광청의 침사추이 명소 안내](https://www.discoverhongkong.com/eng/attractions/top-things-to-see-and-do-around-tsim-sha-tsui-promenade.html)와 [아트파크 안내](https://www.discoverhongkong.com/eng/place-to-go/travel.guide-art-park.html)를 참고했습니다. 식사 자료는 이 출처의 식당 정보가 아니라 교육을 위해 만든 예시입니다.
