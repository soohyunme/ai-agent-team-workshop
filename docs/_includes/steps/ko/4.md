**워크플로(workflow)**는 여러 작업의 실행 순서를 연결한 구성입니다. 이번 템플릿에는 AI의 역할, 지시문, 연결이 준비돼 있습니다.

## 템플릿 불러오기

1. [여행 템플릿]({{ '/assets/templates/hong-kong-day-trip-team-starter-v0.1.json' | relative_url }})을 다운로드하세요. 페이지의 **여행 템플릿 다운로드** 버튼을 사용할 수도 있습니다.
2. 파일이 `hong-kong-day-trip-team-starter-v0.1.json`으로 저장됐는지 확인하세요. **JSON**은 파일 형식의 이름이며, 파일 내용을 직접 편집할 필요는 없습니다.
3. Sim 왼쪽에서 **Workflows** 제목을 찾으세요.
4. 제목 옆 **··· → Import(파일 불러오기)**를 선택하세요.
5. 다운로드한 JSON 파일을 선택하세요.
6. 목록에 추가된 **Hong Kong Day Trip Team - Starter v0.1**을 여세요.

링크를 눌렀을 때 파일 내용이 글자로 표시되면 페이지의 다운로드 버튼으로 저장하세요. 파일 내용을 개별 AI 상자에 붙여넣지 마세요.

## 화면 구성 확인하기

화면의 상자 하나를 **블록(block)**이라고 부릅니다. 다음 네 블록이 순서대로 연결돼 있는지 확인하세요.

| 블록 이름 | 역할 |
| --- | --- |
| Start | 여행 요청과 장소 자료 입력 |
| Activity Selector | 활동 추천 |
| Day Planner | 일정 구성 |
| Plan Reviewer | 조건 확인과 초안 수정 |

**모델(model)**은 답변을 생성하는 AI를 뜻합니다. 이번 실습에서는 템플릿에 지정된 모델을 그대로 사용합니다.
