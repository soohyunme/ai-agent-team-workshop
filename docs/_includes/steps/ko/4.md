## A. 새 워크플로 만들기

**워크플로(workflow)**는 작업의 실행 순서와 정보 전달을 구성한 것입니다. 완성본을 불러오는 대신 직접 만들어봅니다.

1. Sim 왼쪽 **Workflows 옆 +**를 눌러 새 워크플로를 만드세요.
2. 새 이름을 우클릭하고 **Rename**으로 `My Hotel Review Team`이라고 이름을 붙이세요.
3. **Start**가 있는지 확인하세요. 없다면 오른쪽 **Toolbar**에서 Start를 찾아 빈 작업 화면으로 끌어오세요. Start는 하나만 둡니다.

화면의 상자 하나를 **블록(block)**이라고 합니다. Start와 세 Agent 블록을 사용합니다.

## B. 고객 리뷰와 답변 말투 입력하기

Start를 클릭하고 **Editor**를 여세요. 입력 항목의 **+**로 아래 두 항목을 만들고 Name·Type·Value를 입력하세요. Description은 선택 사항입니다.

| Name | Type | Value | 의미 |
| --- | --- | --- | --- |
| review | string | `Clean room and friendly staff. Long check-in wait; breakfast hours were not explained.` | 가상 고객 리뷰 |
| tone | string | `warm and professional` | 따뜻하고 전문적인 답변 말투 |

`string`은 글자로 된 값입니다. Name은 그대로 입력하고 Value는 한 줄로 붙여넣으세요. 이번 예시에는 별도의 공통 변수나 자료 파일이 필요하지 않습니다.

## C. 리뷰의 내용과 알 수 없는 것 구분하기

가상 리뷰의 뜻은 다음과 같습니다.

> 객실은 깨끗하고 직원도 친절했습니다. 다만 체크인 대기가 길었고, 조식 이용시간을 안내받지 못했습니다.

| 리뷰에서 확인할 수 있는 의견 | 아직 알 수 없는 것 |
| --- | --- |
| 객실·직원에 대한 긍정 평가 | 모든 고객이 같은 평가를 하는지 |
| 체크인 대기에 대한 불편 | 대기 원인·실제 대기시간·개선 여부 |
| 조식 이용시간 안내에 대한 불편 | 실제 조식 시간·안내 누락 원인·보상 정책 |

한 고객의 진술을 호텔 전체의 사실이나 반복 발생의 근거로 확대하지 마세요. 실제 고객 정보는 입력하지 않습니다. 이번 팀은 **내부 제안과 답변 초안만 생성**하며 실제 업무를 수행하거나 고객에게 보내지 않습니다.
