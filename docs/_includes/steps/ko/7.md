## 수정한 팀 실행하기

1. 변경 내용을 저장하세요. 별도의 저장 버튼이 표시되면 저장을 완료하세요.
2. **Run**을 눌러 팀을 다시 실행하세요.
3. **Logs**에서 새로운 실행 시각을 확인하고 **Trip Planner → content**를 여세요.

## 결과 검토하기

아래 질문을 기준으로 새 일정을 살펴보세요.

- 선택한 관심사에 맞는 활동이 포함돼 있나요?
- 식사 후보의 지역이 최종 일정에 남아 있는 관광지의 지역과 일치하나요?
- 식사 후보가 음식 취향을 반영하며, 가상 예시임을 표시하나요?
- 관광 활동은 한 개이고 휴식이 하나 이상 포함돼 있나요?
- 제공된 자료 밖의 장소나 근거 없는 시간·가격을 추가하지 않았나요?
- 수정 사항 또는 이미 조건을 충족했다는 설명이 있나요?

이전 일정이 이미 조건에 맞았다면 결과의 변화가 작을 수 있습니다. 변화의 크기보다 **요청한 조건을 따르는지**를 확인하세요.

팀 전체를 다시 실행하면 앞 에이전트의 답변도 달라질 수 있습니다. 결과의 모든 차이가 수정한 지시문 하나 때문이라고 단정하지 마세요. 조건을 지키지 못한 부분은 표시하고 진행자와 함께 확인하세요.

## 실제 여행에 활용하기 전

실제 식당·메뉴와 운영시간·가격·이동시간·접근성은 별도로 확인하세요. 같은 지역이라는 표시만으로 가까운 거리나 편리한 이동이 보장되지는 않습니다.

## 선택 실습

시간이 남으면 관심사나 일정 조건을 하나 더 바꿔 실행해보세요. 다른 여행지에 적용하려면 장소 자료도 교체하고 해당 정보의 정확성을 별도로 확인해야 합니다.
