<h2 id="help">막혔을 때</h2>

| 상황 | 다음 행동 |
| --- | --- |
| 인증 메일이 안 옴 | 주소와 스팸함 확인 |
| 메뉴나 결과 위치를 못 찾음 | 몇 번 단계인지 알리고 도움 요청 |
| 키가 없거나 인증 오류가 남 | 현재 팀이 있는 작업 공간에 `OPENROUTER_API_KEY`로 저장했는지 확인 |
| `429 Provider returned error` | 재실행 반복을 멈추고 진행자에게 오류 전달 |
| 결제 안내가 나옴 | 구매하지 말고 멈춘 단계 기록 |
| AI가 자료가 없다고 함 | Start의 trip과 places Value가 비어 있지 않은지 확인 |
| 예전 답변처럼 보임 | Logs에서 최신 실행 시각 확인 |
| 결과가 크게 달라지지 않음 | 최신 실행인지 확인하고, 관심사와 추가 조건 충족 여부를 점검 |
