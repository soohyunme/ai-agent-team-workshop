## API 키란 무엇인가요?

**API 키**는 프로그램이 외부 서비스를 이용할 때, 누구의 요청인지 확인하는 데 사용하는 인증 코드입니다. 이번 실습에서는 OpenRouter에서 발급한 키를 Sim에 등록해 AI 모델을 사용합니다. 비밀번호처럼 안전하게 관리하고 다른 사람에게 공유하지 마세요.

기존 OpenRouter 계정이 있으면 로그인하세요. 사용할 수 있는 OpenRouter API 키가 이미 있다면 새로 생성할 필요 없이 3단계로 넘어가도 됩니다.

## API 키 생성하기

1. <a href="https://openrouter.ai/" target="_blank" rel="noopener noreferrer">OpenRouter(새 탭)</a>에 접속해 가입하거나 로그인하세요.
2. 이메일 인증을 요청받으면 받은 메일에서 인증을 완료하세요. 메일이 보이지 않으면 스팸함을 확인하세요.
3. 로그인한 상태에서 <a href="https://openrouter.ai/settings/keys" target="_blank" rel="noopener noreferrer">API Keys 화면(새 탭)</a>을 여세요.
4. 새 키를 만드는 항목을 선택하고, 알아보기 쉬운 이름을 입력하세요. 예: `polyu-workshop`
5. 키를 생성한 뒤 복사 버튼을 누르세요. 복사할 대상은 키의 이름이 아니라 **생성된 긴 코드**입니다.
6. 다음 단계에서 Sim에 키를 등록할 때까지 이 화면을 열어 두세요.

**보안 주의:** API 키를 다른 사람에게 보내거나 화면 캡처에 포함하지 마세요. 나중에 사용할 키는 비밀번호 관리자 등 안전한 개인 보관 수단을 이용하세요.
