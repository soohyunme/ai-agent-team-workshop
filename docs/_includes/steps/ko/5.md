## 준비된 요청으로 실행하기

1. **Start**를 클릭하고 오른쪽 **Editor**를 엽니다.
2. **trip → Value**는 이번 여행 요청입니다. 기본값은 항구 풍경·사진·공원에 관심이 있고 여유롭게 하루를 보내고 싶다는 내용입니다.
3. **places → Value**는 제공된 장소 자료입니다. 처음에는 두 항목 모두 그대로 둡니다.
4. 오른쪽 위 **Run**을 누릅니다. 저장된 값을 사용하므로 새 입력창이 뜨기를 기다리지 않습니다.
5. 끝날 때까지 기다립니다. Run을 반복해서 누르지 않습니다.
6. 아래 **Logs**에서 최신 실행을 선택하고 **Plan Reviewer → content**를 읽습니다. content는 AI가 작성한 답변입니다.

완료 확인: 제공된 활동으로 만든 일정 초안이 보입니다. 자료에 없는 시간·가격 등이 사실처럼 쓰였다면 표시해 둡니다. AI의 검토도 정확성을 보장하지 않습니다.

## 전달되는 답변과 지시문 보기

같은 실행의 Activity Selector → Day Planner → Plan Reviewer 답변을 읽습니다. 한 장소가 추천에서 최종 일정으로 어떻게 이어지는지 찾아보세요.

**Day Planner → Editor → Messages**를 엽니다.

| 화면 이름 | 뜻 |
| --- | --- |
| System | 이 AI의 역할·행동 원칙·출력 규칙 |
| User | 이번 작업의 요청과 자료 |

둘 다 AI에게 전달하는 문장이며 **프롬프트**라고 부릅니다. 코드처럼 작성할 필요는 없습니다.

User의 `<activityselector.content>`는 앞 AI의 답변이 들어오는 자리입니다. 실행할 때 Sim이 채웁니다.

| 표시 | 전달되는 내용 |
| --- | --- |
| `<start.trip>` | 여행 요청 |
| `<start.places>` | 제공된 장소 자료 |
| `<activityselector.content>` | 추천 담당의 답변 |
| `<dayplanner.content>` | 일정 구성 담당의 답변 |

기본 실습에서는 이 표시나 블록 이름을 바꾸지 않습니다. 화살표는 실행 순서를, 메시지의 참조는 사용할 결과를 지정합니다.
