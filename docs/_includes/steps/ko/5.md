## 첫 일정 생성하기

1. **Start**를 클릭하고 오른쪽 **Editor(편집)**를 여세요.
2. **trip → Value**에서 여행 요청을 확인하세요. 기본 요청은 항구 풍경·사진·공원에 관심이 있고 여유롭게 하루를 보내고 싶다는 내용입니다.
3. **places → Value**에서 제공된 장소 자료를 확인하세요. 첫 실행에서는 두 항목을 수정하지 마세요.
4. 오른쪽 위 **Run(실행)**을 누르세요. Start에 저장된 값을 사용하므로 별도의 입력창은 열리지 않습니다.
5. 실행이 끝날 때까지 기다리세요. 실행 중에는 Run을 반복해서 누르지 마세요.
6. 아래 **Logs(실행 기록)**에서 최신 실행을 선택한 뒤 **Plan Reviewer → content**를 여세요. content는 AI가 작성한 답변입니다.

일정 초안을 읽고 요청에 맞는 내용인지 살펴보세요. 자료에 없는 시간이나 가격이 사실처럼 제시됐다면 표시해 두세요. AI의 검토 결과도 사람이 확인해야 합니다.

## 역할별 답변 살펴보기

같은 실행 기록에서 **Activity Selector → Day Planner → Plan Reviewer**의 답변을 순서대로 읽어보세요. 추천한 활동 하나가 일정에 반영되고 검토되는 과정을 찾아보세요.

이어서 **Day Planner → Editor → Messages(메시지)**를 여세요.

| 메시지 종류 | 용도 |
| --- | --- |
| System | 에이전트의 역할, 행동 원칙, 출력 규칙 |
| User | 이번 실행에서 처리할 요청과 자료 |

AI에게 전달하는 지시문을 **프롬프트(prompt)**라고 합니다. 일반 문장으로 작성할 수 있습니다.

User 메시지의 `<activityselector.content>`는 활동 추천 담당의 답변을 가져오는 **참조**입니다. 실행할 때 Sim이 이 자리에 해당 답변을 넣습니다.

| 참조 표시 | 전달되는 내용 |
| --- | --- |
| `<start.trip>` | 여행 요청 |
| `<start.places>` | 제공된 장소 자료 |
| `<activityselector.content>` | 활동 추천 담당의 답변 |
| `<dayplanner.content>` | 일정 구성 담당의 답변 |

화살표는 실행 순서를 나타내고, 메시지의 참조는 전달할 내용을 지정합니다. 기본 실습에서는 블록 이름과 참조 표시를 변경하지 마세요.
