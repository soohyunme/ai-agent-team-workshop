1. 왼쪽 목록에서 다른 팀을 열었다가 내 팀으로 돌아와 수정한 문장이 남아 있는지 봅니다.
2. 화면에 저장 동작이 있으면 완료하고, 로그아웃했다가 다시 로그인해 같은 팀을 실행합니다.
3. 파일로도 남기려면 왼쪽 목록의 팀 이름을 우클릭하고 **Export(파일로 내보내기)**를 선택합니다. [공식 가져오기·내보내기 안내](https://docs.sim.ai/quick-reference)

다음에는 저장된 팀을 열어 Start의 trip 내용을 바꾸고 Run을 누르면 됩니다. 내보낸 파일은 팀 설정을 담습니다. 무료 이용권이나 실제 개인 키가 담긴 것은 아닙니다. 다른 곳에 키를 직접 입력했다면 파일을 공유하기 전에 포함 여부를 확인하세요.
