2. **Start의 interests·food·pace** 값과 **Trip Planner → User**에 추가한 요청가 남아 있는지 확인하세요.
3. 다음에 사용할 때는 같은 계정으로 로그인해 팀을 열고, **Start의 interests·food·pace → Value**를 수정한 뒤 **Run**을 누르세요.

## 선택: 파일로 보관하기

왼쪽 목록의 팀 이름을 우클릭하고 **Export(파일로 내보내기)**를 선택하면 파일로 보관할 수 있습니다. [Sim 공식 가져오기·내보내기 안내](https://docs.sim.ai/quick-reference)

내보낸 파일에는 팀 구성이 담깁니다. 모델을 다시 사용하려면 이용 가능한 계정과 API 연결이 필요하며, 파일 자체가 무료 사용량을 제공하지는 않습니다.

**공유 전 확인:** 이번 가이드에서는 실제 API 키 대신 저장된 키를 불러오는 참조를 사용합니다. 실습 중 키나 개인 자료를 직접 입력했다면 내보낸 파일에 포함됐는지 확인하고, 민감한 내용을 제거한 뒤 공유하세요.

## 내 작업에 맞는 팀으로 응용하기

실습 후에는 관심사나 여행 조건을 바꿔 같은 팀을 반복해서 사용해보세요.

### 3분 활동: 내 과제를 위한 AI 팀 구상하기

자신의 과제나 관심 있는 작업 하나를 골라 아래 네 항목을 개인 메모에 짧게 적어보세요. 지금 새 팀을 구현할 필요는 없습니다. 작성한 메모를 다음에 팀을 만들 때 출발점으로 사용하세요.

1. **목표:** 어떤 결과물을 만들고 싶나요?
2. **역할:** 어떤 일을 나누어 맡기면 좋을까요?
3. **전달할 내용:** 다음 담당자에게 어떤 자료와 결과가 필요한가요?
4. **확인 기준:** 결과가 요청한 조건과 근거에 맞는지 어떻게 확인할까요?

예를 들어 발표 준비에는 **제공된 자료 요약 → 발표 목차 구성 → 근거와 누락 검토**라는 역할을 둘 수 있습니다. 여행 팀의 입력만 바꾸는 것이 아니라, 각 역할의 지시문과 전달할 내용도 새 목표에 맞게 바꿔야 합니다.

Sim에서 계속 실험해도 되고, 다른 도구로 이 구조를 구현해도 됩니다. 다른 도구에서는 설정과 연결을 새로 구성해야 할 수 있으며, Sim에서 내보낸 파일을 그대로 사용할 수 있다는 뜻은 아닙니다.

중요한 것은 특정 서비스에 익숙해지는 것보다 **역할을 나누고, 결과를 전달하고, 지시를 수정하며 자신의 작업에 활용하는 것**입니다. 여러 역할이 필요하지 않은 간단한 작업은 AI 하나로 시작해도 됩니다. 실제 활용 전에는 최종 결과를 직접 확인하고, 과제에 사용할 때는 수업의 AI 활용 지침을 따르세요.
