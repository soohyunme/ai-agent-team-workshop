## 저장한 팀 다시 열기

1. 수정한 내용을 저장한 뒤 같은 팀을 다시 여세요. 별도의 저장 버튼이 표시되면 먼저 저장을 완료하세요.
2. **Start → trip**의 요청과 **Trip Planner → System**에 추가한 지시가 남아 있는지 확인하세요.
3. 다음에 사용할 때는 같은 계정으로 로그인해 팀을 열고, **Start → trip → Value**를 수정한 뒤 **Run**을 누르세요.

## 선택: 파일로 보관하기

왼쪽 목록의 팀 이름을 우클릭하고 **Export(파일로 내보내기)**를 선택하면 파일로 보관할 수 있습니다. [Sim 공식 가져오기·내보내기 안내](https://docs.sim.ai/quick-reference)

내보낸 파일에는 팀 구성이 담깁니다. 모델을 다시 사용하려면 이용 가능한 계정과 API 연결이 필요하며, 파일 자체가 무료 사용량을 제공하지는 않습니다.

**공유 전 확인:** 제공된 템플릿에는 실제 API 키 대신 키를 불러오는 참조가 들어 있습니다. 실습 중 키나 개인 자료를 직접 입력했다면 내보낸 파일에 포함됐는지 확인하고, 민감한 내용을 제거한 뒤 공유하세요.

## 이후 활용하기

관심사나 여행 조건을 바꿔 같은 팀을 반복해서 사용해보세요. 이번 실습의 핵심은 **역할을 나누고, 결과를 전달하고, 지시를 수정해 원하는 결과에 가까워지는 과정**입니다. 실제 활용 전에는 최종 결과를 직접 확인하세요.
