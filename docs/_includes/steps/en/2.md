## What is an API key?

An **API key** is an authentication code used to identify whose requests a program is making when it uses an external service. In this workshop, you will register a key issued by OpenRouter in Sim to use AI models. Protect it like a password and do not share it with others.

If you already have an OpenRouter account, sign in. If you have a usable OpenRouter API key, you can continue to step 3 without creating another.

## Create an API key

1. Open <a href="https://openrouter.ai/" target="_blank" rel="noopener noreferrer">OpenRouter (new tab)</a> and sign up or sign in.
2. If email verification is requested, complete it using the message in your inbox. Check spam or junk if the message is missing.
3. While signed in, open the <a href="https://openrouter.ai/settings/keys" target="_blank" rel="noopener noreferrer">API Keys page (new tab)</a>.
4. Select the option to create a new key and give it a recognizable name, such as `polyu-workshop`.
5. Create the key and select its copy button. Copy the **generated long code**, not the name you gave the key.
6. Keep this screen open until you have registered the key in Sim in the next step.

**Security note:** Do not send your API key to others or include it in screenshots. If you need to keep it for later, use a secure personal storage method such as a password manager.
