## A. Create a new workflow

A **workflow** defines task order and information handoffs. You will build one rather than import the completed example.

1. Select **+ beside Workflows** in Sim's left sidebar.
2. Right-click its name and select **Rename**. Call it `My Hotel Review Team`.
3. Check for **Start**. If absent, drag Start from the right-hand **Toolbar** onto the canvas. Keep only one Start.

Each box is a **block**. You will use Start and three Agent blocks.

## B. Enter the guest review and reply tone

Select Start and open **Editor**. Use **+** in the input fields section to add the two entries below. Fill in Name, Type and Value; Description is optional.

| Name | Type | Value | Meaning |
| --- | --- | --- | --- |
| review | string | `Clean room and friendly staff. Long check-in wait; breakfast hours were not explained.` | Fictional guest review |
| tone | string | `warm and professional` | Reply tone |

`string` means text. Keep the field names unchanged and paste each value as one line. This example needs no separate shared variable or data file.

## C. Explore the information each role needs

The fictional review praises the room and staff, but reports a long check-in wait and missing breakfast-hours information.

| Feedback | How roles use it |
| --- | --- |
| Positive room and staff experience | The analyst summarizes it; the communicator uses it when thanking the guest |
| Check-in wait complaint | The analyst identifies it; the operations advisor proposes an improvement |
| Breakfast-hours information complaint | The analyst identifies it; the operations advisor proposes clearer guidance |

The communicator reads the original review and both earlier results to draft a reply. Consider what information each role needs to receive.

**Exercise scope:** Use the fictional review to generate internal proposals and a reply draft only. Do not enter real guest information.
