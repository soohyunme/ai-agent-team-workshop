Use **Starter v0.2** for this exercise. If you previously imported an older version, import the new file as a separate workflow; you do not need to delete your existing team.

A **workflow** connects tasks in an execution sequence. This template already contains the AI roles, instructions and connections.

## Import the template

1. Download the [travel template]({{ '/assets/templates/hong-kong-day-trip-team-starter-v0.2.json' | relative_url }}). You can also use the **Download template** button on this page.
2. Check that the file is saved as `hong-kong-day-trip-team-starter-v0.2.json`. **JSON** is the file format; you do not need to edit its contents.
3. Find the **Workflows** heading in Sim's left sidebar.
4. Select **··· → Import** beside that heading.
5. Select the downloaded JSON file.
6. Open **Hong Kong Day Trip Team - Starter v0.2** from the workflow list.

If the file opens as text in your browser, use this page's download button to save it. Do not paste the file contents into an individual AI box.

## Check the team layout

Each box on the screen is called a **block**. Check that these four blocks are connected in order.

| Block name | Role |
| --- | --- |
| Start | Holds the travel request and activity information |
| Sightseeing Planner | Selects sightseeing activities and their areas |
| Food Planner | Selects food examples matching those areas and preferences |
| Trip Planner | Combines sightseeing, a food example and rest into an itinerary |

A **model** is the AI that generates an answer. Keep the model selected in the template for this exercise.

## About the supplied cards

Start's places field contains sightseeing cards and fictional food cards. Each has an ID and area so you can trace how the food specialist uses the sightseeing selection.

The short sightseeing descriptions and area labels draw on the Hong Kong Tourism Board's [Tsim Sha Tsui attractions guide](https://www.discoverhongkong.com/eng/attractions/top-things-to-see-and-do-around-tsim-sha-tsui-promenade.html) and [Art Park guide](https://www.discoverhongkong.com/eng/place-to-go/travel.guide-art-park.html). The food cards are teaching examples, not restaurant information from these sources.
