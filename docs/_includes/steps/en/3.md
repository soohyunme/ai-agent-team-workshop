Sim calls your working area a **workspace**. This is where you create and manage your AI teams.

If `OPENROUTER_API_KEY` is already registered and usable in the workspace for this exercise, continue to step 4. Having a Sim account alone does not complete the key connection.

## Connect your API key

1. Open [Sim](https://www.sim.ai/) in a new tab and sign up or sign in.
2. Complete any required email verification and open your workspace.
3. Open the workspace's **Settings → Secrets**, where private credentials are stored.
4. Enter the following values in an empty row in the Workspace section.

| Field | Value to enter |
| --- | --- |
| Key / Name | `OPENROUTER_API_KEY` |
| Value | Your personal API key copied from OpenRouter |

<ol start="5">
<li markdown="1">Select **Save**.</li>
<li markdown="1">Check the saved key name, then return to the Sim workspace.</li>
</ol>

The AI team you will import in the next step uses the key stored under the name `OPENROUTER_API_KEY`. The expression `{% raw %}{{OPENROUTER_API_KEY}}{% endraw %}` in the example refers to that saved key; it is not the key itself. [Sim's official settings guide](https://docs.sim.ai/platform/credentials)

**Note:** Keep the key name and the actual key in their respective fields. If you cannot find the settings, ask the facilitator. The similarly named **Sim API keys** feature is not used in this step.
