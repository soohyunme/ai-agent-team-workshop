## A. Run the team you built

1. Select **Run** once. It uses the saved Start values; no separate input window opens.
2. Wait for completion without repeatedly selecting Run.
3. In **Logs**, select the latest run and read the three specialists' **content** outputs in order.
4. Open **Trip Planner → content** to view the final draft.

Did the food specialist use the selected sightseeing areas? Does the final draft use both specialists' recommendations? Check that food choices are clearly labeled as fictional examples rather than real restaurants.

## B. Give the team a new travel condition

**Mission: change the plan to include one sightseeing activity, a matching meal in that area and a rest break.**

First, decide which role should receive the request. Here, give the condition to the **itinerary organizer**, which turns the earlier recommendations into a final plan. What should change, and what information should be preserved?

Append the following sentence to **Trip Planner → Editor → Messages → User**. Leave existing references, System and the Start inputs unchanged.

```text
For this trip, include only one sightseeing activity, one matching fictional meal if available, and one rest break.
```

Run once more and inspect the latest result.

- Is there only one sightseeing activity?
- Does the meal match a retained sightseeing area and the food preference, or explain that no match is available?
- Is there a rest break?
- Does the result avoid inventing places, times or prices?

If the earlier result already met the condition, the difference may be small. Rerunning the team can also change earlier answers, so check **whether the requested conditions are followed**, rather than attributing every difference to your edit.

## C. Optional: make the result easier to read

If time allows, leave User unchanged and append this rule to **Trip Planner's System**. Do not remove the existing System instructions.

```text
Format the itinerary as a short numbered list. Keep the card IDs, areas, fictional-food labels and Before you go note.
```

Run again and check the presentation format. **User supplies this trip's request; System sets the specialist's general rules.** Change one at a time rather than adding conflicting instructions.

## Before using the draft for travel

Verify actual restaurants, menus, opening hours, prices, travel times and accessibility separately. Matching area labels do not guarantee short distances or convenient travel.
