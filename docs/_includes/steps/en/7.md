## B. Make the guest reply shorter

Read the first reply. Is it too long for a guest to read? **Make it shorter while keeping both concerns.**

1. Open `Guest Reply Writer` and go to **Editor → Messages → User**.
2. Keep the existing content and add the following sentence at the end. Leave System unchanged.

```text
For this reply, address both the check-in wait and the missing breakfast-hours information. Keep it under 90 words.
```

This asks the writer to **mention both the check-in wait and the missing breakfast-hours information, using fewer than 90 words.**

3. Select **Run** again and compare the latest reply in Logs with the previous reply.

- Is the reply shorter? Is it under 90 words?
- Are both concerns still included?
- Does it thank the guest and acknowledge their concerns?

The key idea is that **you can adjust the final result by changing the request given to one role, without rebuilding the whole structure.**

If the first reply already met the conditions, changes may be small. AI responses can vary between runs, so check whether the requested conditions are met rather than expecting identical wording.
