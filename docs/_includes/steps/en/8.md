## Reopen the saved team

1. Save your edits and reopen the same team. Complete any separate save action shown before leaving it.
2. Check that the **review and tone** values in **Start** and the added request in **Guest Reply Writer → User** are still present.
3. For future use, sign in with the same account, open the team, change the **Value** fields for **review and tone** in **Start** and select **Run**.

## Optional: export a file copy

Right-click the team's name in the left sidebar and select **Export** to keep a file copy. [Sim's official import and export guide](https://docs.sim.ai/quick-reference)

The exported file contains the team configuration. Future model use still requires an available account and API connection; the file does not provide free usage allowances.

**Before sharing:** This guide uses a reference to a saved key rather than the actual secret. If you entered a key or personal information during the exercise, check whether it appears in the exported file and remove sensitive content before sharing.

## Adapt the team to your own work

After the workshop, reuse the same team with different fictional reviews or reply tones.

### Three-minute activity: sketch a team for your own task

Choose an assignment or project and briefly answer the four questions below in your own notes. You do not need to build a new team now. Keep your notes as a starting point for your next team.

1. **Goal:** What output do you want to create?
2. **Roles:** Which tasks could you assign to separate specialists?
3. **Handoffs:** What information and results does the next specialist need?
4. **Checks:** How will you check the output against your requirements and evidence?

For example, a presentation team could **summarize supplied material → draft a presentation outline → check evidence and omissions**. Adapting the hotel review response system means changing each role's instructions and the information passed between roles, not just replacing the original review.

You can continue experimenting in Sim or implement the structure with another tool. Other tools may require you to rebuild the settings and connections; this does not mean they can directly use a file exported from Sim.

What matters is **dividing roles, passing results and refining instructions to support your own work**, rather than mastering a particular service. For a simple task that does not need separate roles, starting with one AI is fine. Review the final result yourself before using it, and follow your course's AI-use guidelines for assignments.
