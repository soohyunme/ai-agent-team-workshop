## A. Generate the first itinerary

1. Select **Start** and open **Editor**.
2. Read the sightseeing interests, food preference and pace under **trip → Value**. The defaults request harbour views, photography, parks and local dishes.
3. Under **places → Value**, read the sightseeing and fictional food cards, each with an ID and area. Leave the values unchanged for the first run.
4. Select **Run**. It uses the saved Start values; no separate input window opens.
5. Wait for completion without repeatedly selecting Run.
6. In **Logs**, select the latest run and open **Trip Planner → content**, the written answer.

Check how sightseeing, a food example and rest are combined. Note any fictional meal presented as a real restaurant or any unsupported travel times.

## B. Check the three specialists' results

Read the same run's answers in order.

| Specialist | What to check |
| --- | --- |
| Sightseeing Planner | Which sightseeing activities and areas were selected? |
| Food Planner | Were food examples chosen using those areas and the food preference? |
| Trip Planner | How were both specialists' recommendations combined? |

For example, if a selected sightseeing activity is in Tsim Sha Tsui, check whether the food specialist chooses a fictional food card labeled Tsim Sha Tsui. If no card matches the area and preference, it should report missing information rather than invent an option.

## C. Explore instructions and handoffs

Written instructions to AI are called **prompts** and can be ordinary sentences.

Open **Food Planner → Editor → Messages**.

| Message type | Purpose |
| --- | --- |
| System | The agent's role, behavior and output rules |
| User | The request and material for the current run |

The reference `<sightseeingplanner.content>` in Food Planner's User message brings in the sightseeing specialist's answer. The food specialist reads this answer alongside the original cards.

<details markdown="1">
<summary>Reference: all handoff expressions</summary>

| Reference | Information passed |
| --- | --- |
| `<start.trip>` | Sightseeing interests, food preferences and travel conditions |
| `<start.places>` | Sightseeing and fictional food cards with area labels |
| `<sightseeingplanner.content>` | Selected sightseeing activities and areas |
| `<foodplanner.content>` | Food examples and why they match the sightseeing areas |

</details>

Trip Planner receives both specialists' answers. Arrows specify the execution order; references specify the information passed. Keep block names and reference expressions unchanged in the basic exercise.
