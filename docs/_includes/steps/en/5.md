## Generate the first itinerary

1. Select **Start** and open **Editor** on the right.
2. Read the travel request under **trip → Value**. The starting request specifies harbour views, photography and parks at a relaxed pace.
3. Read the supplied activity information under **places → Value**. Leave both fields unchanged for the first run.
4. Select **Run** at the top right. The team uses the saved Start values; no separate input window opens.
5. Wait for the run to finish. Do not repeatedly select Run while it is processing.
6. Open **Logs** at the bottom, select the latest run and open **Plan Reviewer → content**. Content is the AI's written answer.

Read the draft and consider how well it matches the request. Note any times or prices presented as facts without support in the supplied information. AI-reviewed output still needs human review.

## Explore each role's answer

Within the same run, read **Activity Selector → Day Planner → Plan Reviewer** in order. Follow one recommended activity through the proposed itinerary and review.

Next, open **Day Planner → Editor → Messages**.

| Message type | Purpose |
| --- | --- |
| System | The agent's role, behavior and output rules |
| User | The request and material for the current run |

Written instructions given to AI are called **prompts**. They can be ordinary sentences.

The expression `<activityselector.content>` in the User message is a **reference** to the Activity Selector's answer. Sim inserts that answer when the team runs.

| Reference | Information passed |
| --- | --- |
| `<start.trip>` | Travel request |
| `<start.places>` | Supplied activity information |
| `<activityselector.content>` | Activity Selector's answer |
| `<dayplanner.content>` | Day Planner's answer |

Arrows indicate the execution order; references in messages specify the information to pass. Keep the block names and reference expressions unchanged during the basic exercise.
