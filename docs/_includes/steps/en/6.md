## A. Change the travel preferences

Replace **Start → trip → Value** with the example below, or write a request based on your own interests. **Keep places unchanged.**

```text
Plan a relaxed one-day visit to Hong Kong using only the supplied activity cards.
Interests: art and harbour views.
Pace: relaxed.
Return a draft, not a confirmed travel schedule.
```

This example requests a trip focused on art and harbour views. Change the `Interests` line to reflect your preferences.

## B. Add a review condition

Open **Plan Reviewer → Editor → Messages → System**. **Append** the following text to the existing instructions. Do not delete the existing message or change User.

```text
Keep at most two sightseeing activities and include at least one rest break. Remove extra sightseeing activities from the draft if needed. Explain briefly what you changed, or say that the draft already met this rule.
```

This instruction limits the draft to two sightseeing activities and asks for at least one rest break. It also requests a brief explanation of any changes.

In A, you change the **request for this run**. In B, you add a **rule for the agent to follow**. In the next step, you will check how both changes are reflected in the final itinerary.
